CLI命令 会话命令 内置技能 可用插件

🖥️ CLI 命令行参考

在终端输入的命令。每条命令包含：用法、功能说明、典型使用场景。

启动

hermes
启动交互式聊天会话
最常用的启动方式，直接进入对话模式。就像打开一个智能终端，可以和 Agent 自由对话、问问题、让它帮你写代码、查资料、管理文件。每次启动都是新会话，上下文干净。
hermes chat -q "问题"
单次查询，非交互模式，问完即退出
适合脚本调用或定时任务。不进入对话循环，Agent 回答问题后立即退出。比如在 bash 脚本里用 hermes 处理数据、在 cron 定时任务里让 Agent 每天生成报告。
hermes --resume SESSION
恢复指定 ID 的会话，继续之前未完成的工作
代码写到一半、分析做到一半，第二天用这个命令无缝继续。SESSION ID 可以通过 hermes sessions list 查看。Agent 会重新加载之前的完整对话历史。
hermes --continue [名称]
恢复最近会话或按名称搜索恢复
比 --resume 更友好，不需要记 ID。直接 hermes --continue 恢复最近一次对话，或 hermes --continue "项目A" 按名称搜索。
hermes --profile NAME
使用指定配置文件启动，切换不同身份/环境
你可以在不同场景用不同配置：工作用工作 profile（连公司 API），个人用个人 profile（用自己的 key）。每个 profile 有独立的配置、技能和记忆。
hermes --yolo
跳过所有危险命令的确认提示，自动执行
适合信任度高的自动化场景。正常模式下 Agent 执行 rm、chmod 等危险命令会先确认，加 --yolo 直接执行。慎用，建议只在沙箱环境或定时任务中使用。
hermes --skill NAME
启动时预加载指定技能，直接进入专项工作模式
比如 hermes --skill a-stock-intelligence-agent 启动后就直接具备 A 股分析能力。省去进入聊天后再加载技能的步骤。
hermes --worktree
隔离 git 工作树模式，并行处理多个代码分支
如果你同时在改多个 PR 或多个 feature 分支，每个 --worktree 实例操作独立的工作目录，互不干扰。

模型

hermes model
交互式选择模型和提供商，可视化切换
打开一个 TUI 菜单，列出你所有已配置的模型（DeepSeek、Claude、GPT 等），方向键选择，回车切换。适合想试试不同模型效果的时候。
hermes chat -m MODEL
指定模型进行对话，临时覆盖默认模型
比如日常用便宜的 DeepSeek，遇到复杂任务临时切换到 Claude：hermes chat -m claude-sonnet-4。只影响这一次对话。
hermes chat --provider P
强制指定 API 提供商
同一个模型可能有多个供应商（如通过 OpenRouter 或直接 API），用这个调参 API 路由。也用于 API 额度管理，在多个供应商之间切换。

配置

hermes setup
交互式配置向导，一步步设置 Hermes
第一次安装 Hermes 后必跑的命令。向导会引导你：选择模型、配置 API Key、设置消息平台等。也可以随时重跑修改配置。
hermes config
查看当前完整配置
打印所有配置项的当前值。快速确认模型、工具集、网关等设置是否正确。
hermes config edit
用默认编辑器打开 config.yaml 手动修改
适合需要批量修改配置或调整高级选项的情况。会自动打开记事本/vim/vscode 等系统默认编辑器。
hermes config set KEY VAL
命令行直接设置单个配置项
不需要打开编辑器，一行命令搞定。比如 hermes config set model claude-sonnet-4。适合脚本化配置管理。
hermes config path
打印配置文件所在路径
想知道 config.yaml 到底在哪？这个命令告诉你绝对路径。默认在 ~/.hermes/config.yaml。
hermes config check
检查配置完整性和版本兼容性
Hermes 升级后，有些配置项可能过时或缺失。这个命令会扫描并报告哪些配置需要更新。
hermes config migrate
自动将旧版本配置迁移到新版本格式
升级 Hermes 后运行，自动把旧配置转成新格式，不需要手动改 yaml。
hermes doctor [--fix]
全面健康检查：依赖、环境、配置
Hermes 跑不起来？先跑这个。检查 Python 版本、Node.js、npm、各依赖是否就绪。加 --fix 自动尝试修复常见问题。
hermes status [--all]
显示所有组件运行状态
查看网关是否在线、有哪些定时任务在跑、各消息平台连接状态。加 --all 显示详细信息。

认证

hermes auth
交互式管理所有 API 凭证
一个 TUI 界面管理所有模型供应商的 API Key。添加、删除、查看，不用手改配置文件。
hermes auth add PROVIDER
为指定供应商添加 API Key 或 OAuth 凭证
比如 hermes auth add deepseek 然后输入 API Key。支持 API Key、OAuth Token 等多种认证方式。
hermes auth list
列出所有已配置的认证信息
查看你已经接入了哪些模型供应商，哪些有有效凭证。不会显示密钥明文。
hermes auth remove P
删除某个供应商的认证凭证
API Key 过期或想换 Key 时使用。先 remove 旧的，再 add 新的。

工具

hermes tools
交互式 TUI 管理工具集的启用/禁用
Hermes 有很多工具集（浏览器、终端、Python 执行等）。这个命令打开可视化界面，方向键选择、空格切换启禁。
hermes tools list
列出所有工具集及启用状态
快速查看当前有哪些工具可用。终端输出，一目了然。
hermes tools enable N
启用某个工具集（如 browser、vision）
默认有些工具是关闭的。比如想用浏览器自动化，先 hermes tools enable browser。
hermes tools disable N
禁用某个工具集，减少 token 消耗
不需要的工具关掉可以节约上下文窗口。比如不写代码的时候可以关掉 terminal。

技能

hermes skills list
列出本地已安装的所有技能
技能是 Hermes 的专业知识包。这个命令看本地装了哪些，每个技能的名字和简介。
hermes skills search Q
在技能市场中搜索技能
不知道有没有你需要的技能？搜一下。比如 hermes skills search "python 量化" 搜索量化交易相关技能。
hermes skills install ID
从技能市场安装指定技能
找到想要的技能后，用 ID 安装。比如 hermes skills install akshare-stock。安装后需要 /reset 刷新。
hermes skills inspect ID
预览技能内容，不安装
安装前想先看看技能里有什么？inspect 展示完整内容但不安装，看完再决定要不要装。
hermes skills config
按平台配置技能的启用/禁用
同一个技能可以只在特定平台生效。比如「飞书集成」技能只在飞书平台启用，CLI 端不加载。
hermes skills check
检查已安装技能是否有更新
技能作者可能发布了新版本。这个命令扫描本地技能并标记哪些需要更新。
hermes skills update
批量更新所有过期技能到最新版
一键升级所有可以更新的技能。建议定期运行保持技能最新。
hermes skills uninstall N
卸载不再需要的技能
清理不用的技能减少加载时间。卸载后不影响已有对话。
hermes skills publish PATH
将本地技能发布到技能注册表
你写了一个好用的技能想分享给社区？运行这个命令发布。需要先在技能市场注册账号。
hermes skills browse
浏览技能市场中所有可用技能
打开一个交互式浏览器，可以按分类、热度、评分筛选。发现你不知道但可能需要的技能。
hermes skills tap add R
添加第三方 GitHub 仓库作为技能来源
除了官方技能市场，还可以接入社区维护的技能仓库。比如某人维护的 A 股技能合集。

MCP

hermes mcp serve
将 Hermes 作为 MCP 服务器运行，供其他工具调用
MCP（Model Context Protocol）是 AI 工具间的通用协议。启动这个模式后，VS Code、Cursor 等 IDE 可以直接调用 Hermes 的能力。
hermes mcp add NAME
添加外部 MCP 服务器，扩展工具集
接入外部 MCP 服务（如文件系统服务、数据库查询服务），Hermes 就能使用这些服务提供的工具。
hermes mcp remove NAME
移除已配置的 MCP 服务器
不再需要某个 MCP 服务时删除，减少不必要的连接和 token 消耗。
hermes mcp list
列出所有已添加的 MCP 服务器
查看当前接入了哪些外部 MCP 服务，以及各服务的连接状态。
hermes mcp test NAME
测试与指定 MCP 服务器的连接
添加 MCP 服务后，先测试连接是否正常。会发送一个 ping 请求并报告结果。
hermes mcp configure NAME
选择性地启用/禁用 MCP 服务提供的工具
一个 MCP 服务可能提供几十个工具，你只需要其中几个。这个命令让你精细控制。

网关

hermes gateway run
前台启动网关进程，日志直接输出到终端
调试网关问题时用这个。能看到所有连入的消息、错误日志。退出终端网关就停。
hermes gateway install
将网关安装为系统后台服务，开机自启
生产环境用这个。Windows 上会创建计划任务，Linux/Mac 上会创建 systemd/launchd 服务。
hermes gateway start/stop
启动或停止后台网关服务
控制网关运行状态。修改配置后通常需要 restart 来生效。
hermes gateway restart
重启网关服务，使新配置生效
改了 config.yaml 或加了新平台后，重启网关让变更生效。不会丢失未处理的消息。
hermes gateway status
查看网关运行状态和平台连接情况
检查网关是否在线、连了哪些消息平台、各平台连接是否正常。
hermes gateway setup
配置消息平台接入（飞书/Telegram/微信等）
交互式向导，一步步帮你配置飞书 App ID/Secret、Telegram Bot Token 等。初次接入消息平台必跑。

会话

hermes sessions list
列出最近的对话会话
查看你之前的所有对话记录。显示会话 ID、标题、时间、消息数。
hermes sessions browse
交互式会话浏览器，搜索和恢复历史对话
比 list 更好用的历史会话管理。可以搜索、预览、选择恢复。类似聊天软件的历史记录。
hermes sessions export OUT
导出指定会话为 JSONL 格式
备份重要对话、分享给他人、或用其他工具分析对话数据。JSONL 格式每行一条消息。
hermes sessions rename ID T
给会话起一个有意义的名字
默认会话标题是自动生成的，可能不直观。手动重命名为"年度报告分析"、"Python 爬虫调试"等。
hermes sessions delete ID
删除指定会话及所有记录
清理不需要的对话。删除不可恢复，操作前确认。
hermes sessions prune
批量清理超过 N 天的旧会话
磁盘空间不够？一键清理老对话。默认清理超过 30 天的，可用 --older-than N 调整天数。
hermes sessions stats
会话库存储统计
显示总共有多少次会话、占用多少磁盘空间、最老的会话是什么时候的。帮你判断要不要清理。

定时

hermes cron list
列出所有定时任务及下次执行时间
你有多少自动化任务在跑？每个任务的下次触发时间、调度规则、是否暂停。
hermes cron create SCHED
创建新的定时任务
SCHED 可以是 '30m'（每30分钟）、'every 2h'（每2小时）、'0 9 * * *'（每天9点）。创建时需提供任务提示词和推送目标。
hermes cron edit ID
编辑已有定时任务的调度、提示词或推送目标
修改任务内容、调整执行频率、更换推送渠道。edit 后立即生效。
hermes cron pause/resume ID
暂停或恢复指定的定时任务
临时想停掉某个自动任务？pause。想重新启用？resume。不影响任务配置。
hermes cron run ID
手动立即触发一次定时任务（不等待调度）
刚创建的任务想马上看看效果？不用等到调度时间，直接 run 一次测试。
hermes cron remove ID
删除定时任务
不再需要的自动化任务删除。注意删除和 pause 不同，删除后配置就没了。
hermes cron status
查看定时任务调度器运行状态
检查调度器是否正常、有多少活跃任务、最近执行记录等。

Webhook

hermes webhook subscribe N
创建一个 webhook 路由，接收外部事件
让外部服务（GitHub、飞书、自定义脚本）通过 HTTP POST 触发 Hermes 执行任务。每个 webhook 有唯一 URL。
hermes webhook list
列出所有已创建的 webhook 订阅
查看每个 webhook 的名称、URL、触发条件等。
hermes webhook remove NAME
删除指定的 webhook 订阅
不再需要的外部触发入口，删除后对应的 URL 立即失效。
hermes webhook test NAME
向指定 webhook 发送测试 POST 请求
不用外部服务，本地发一个测试请求验证 webhook 是否正常工作。

配置档

hermes profile list
列出所有已创建的配置档
配置档（Profile）是 Hermes 的多身份系统。每个 profile 有独立的模型配置、技能集和记忆。
hermes profile create NAME
创建新的配置档，隔离不同场景
比如创建一个「工作」profile 连公司 API，一个「个人」profile 用私人账号。每个 profile 完全独立。
hermes profile use NAME
切换当前活动配置档
下班了？hermes profile use personal 切换到个人模式，不再消耗公司 API 额度。
hermes profile delete NAME
删除指定配置档及其所有数据
不再需要的身份配置删除。注意会同时删除该 profile 下的所有技能和记忆。
hermes profile show NAME
查看指定配置档的详细设置
看看某个 profile 用的什么模型、装了哪些技能、连了什么平台。

更新

hermes update
检查并更新 Hermes 到最新版本
自动检测新版本、下载、安装。建议定期运行获取最新功能和修复。
hermes uninstall
完全卸载 Hermes，清理所有文件
当你需要彻底移除 Hermes 时使用。会删除程序文件但默认保留配置和会话数据。

其他

hermes insights [--days N]
查看 Hermes 使用统计和分析
用了多少 token？最常用的命令是什么？哪个模型用得最多？统计过去 N 天的使用数据。
hermes completion bash|zsh
生成 Shell 自动补全脚本
安装后终端里输入 hermes 然后按 Tab 就能自动补全子命令。大幅提升命令行效率。
hermes pairing list/approve/revoke
管理私聊（DM）授权
控制谁能通过消息平台直接私聊你的 Agent。approve 批准，revoke 撤销授权。

💬 会话内斜杠命令

在聊天界面输入的 / 开头的命令，无需退出对话。

会话

/new (/reset)
开始全新会话，丢弃当前上下文
话题完全切换时使用。当前对话的所有上下文清空，Agent 像刚启动一样。等价于退出重新进入。
/clear
清屏并开始新会话（仅 CLI 端）
终端里消息太多看不清？清屏。注意和 /new 一样会清空上下文。
/retry
让 Agent 重新回答你上一条消息
回答不满意？不用重新打字，/retry 让 Agent 换个思路再答一次。相当于撤回重问。
/undo
移除最后一轮对话（你的消息 + Agent 回复）
不小心说了不该说的，或者 Agent 的回答引入了错误信息？/undo 撤销最后一轮，回到上一步状态。
/title [名称]
给当前会话命名，方便以后查找
默认标题是自动生成的摘要。手动改成「年度财报分析」「Python 性能优化」等更有辨识度的标题。
/compress
手动触发上下文压缩，释放 token 空间
对话太长，Agent 开始忘记前面的内容？/compress 把历史对话压缩成摘要，腾出空间继续深入讨论。
/stop
终止当前正在运行的后台任务
Agent 在跑一个很耗时的任务，你想中断它？/stop 立刻停止。任务的中间结果会丢失。
/rollback [N]
回滚最近 N 次文件修改，恢复文件系统快照
Agent 改错了文件？/rollback 把文件恢复到修改前的状态。默认回滚最近一次修改。
/snapshot [sub]
手动创建或恢复 Hermes 完整状态快照
包括配置、会话、文件系统。在做重大操作前先 snapshot 备份，出问题可以恢复。
/background <prompt>
在后台运行一个任务，不阻塞当前对话
比如让 Agent 在后台下载数据，你继续问别的问题。任务完成时会通知你。
/queue <prompt>
排队一个任务，等当前任务完成后再执行
Agent 正在忙，先把下一个任务排上队。不用等，继续聊天。
/steer <prompt>
在 Agent 下一个工具调用后立即插入一条指令
类似在 Agent 的思考过程中插一句话。比如 Agent 在写代码，steer「别忘了加异常处理」。
/resume [名称]
恢复之前命名过的会话
通过 /title 命名的会话，用 /resume 按名称恢复。比记 ID 方便多了。
/goal [text|sub]
设置跨会话持久目标
Agent 会在每次对话开始时回顾你设定的目标，确保不偏离方向。适合长期项目。
/redraw
强制刷新 CLI 界面（终端显示异常时使用）
终端输出乱掉、界面渲染坏了？/redraw 重新绘制整个界面。

配置

/config
在 CLI 中直接查看当前配置（终端格式）
不退出对话就能看配置。比 hermes config 更简化的显示。
/model [名称]
显示当前模型或临时切换到指定模型
/model 看当前用哪个模型。 /model claude-sonnet-4 临时换一个。只影响当前会话。
/personality [名称]
设置 Agent 的个性/系统提示词
想让 Agent 更幽默？更专业？切换不同的 personality 预设。或自定义一个。
/reasoning [级别]
设置推理深度：low/medium/high/xhigh
简单任务用 low 节约成本，复杂分析用 high 获得更深入的思考。直接影响 token 消耗和响应质量。
/verbose
循环切换 Agent 输出的详细程度
四种级别循环：关闭 → 简洁 → 正常 → 详细。想看 Agent 的思考过程时调到详细，想快速看结果时调简洁。
/voice [on|off|tts]
切换语音交互模式
on 开启语音输入/输出，off 关闭，tts 仅输出转语音。适合开车或不方便打字的时候。
/yolo
临时跳过当前会话的所有确认提示
比 --yolo 参数更灵活，在会话中途开启/关闭。批处理文件操作时打开，完成后关闭。
/skin [名称]
更换 CLI 终端颜色主题
不喜欢默认配色？换个皮肤。支持多种预设主题，也可以自定义。

工具

/tools
在 CLI 中打开工具管理界面
和 hermes tools 一样的功能，但不需要退出对话。在聊天中直接管理工具启用/禁用。
/toolsets
列出所有可用工具集及当前状态
快速查看哪些工具开着、哪些关着。比 hermes tools list 信息更紧凑。
/skills
在 CLI 中搜索和管理技能
聊天中突然需要某个技能？/skills 打开技能管理界面，搜索、安装都在聊天内完成。

A股量化分析 (12)

akshare-stock
A股全能分析工具包。基于 akshare 库，覆盖实时行情（大盘指数、个股K线）、技术面（均线/MACD/RSI）、基本面（ROE/毛利率/负债率）、行业板块排行、资金流向、涨跌停统计。支持自然语言查询，是 A 股分析的核心数据引擎。
a-stock-earnings-agent
A股财报深度分析 Agent。主动拉取券商研报、财务指标（利润表/资产负债表/现金流）、业绩预告和公司公告。不做被动汇总，会主动搜索交叉验证，挖掘财报中的异常和风险点。
a-stock-intelligence-agent
A股多 Agent 团队总指挥。下设 L0 望风者（实时情报+舆情监控）和 L1 研究员（宏观/复盘/技术/财报四大方向），自动调度、交叉验证、生成综合研判报告。
a-stock-macro-agent
宏观经济主动研判 Agent。自动拉取 PMI/CPI/PPI/M2/LPR/GDP 等核心宏观数据，结合美联储利率决议、全球市场联动、国内政策信号，判断宏观周期位置和风险偏好。
a-stock-macro-knowledge
宏观分析知识库。收录海峡两岸关系、资源国政策、央行货币政策、A 股政策信号等对市场的传导映射。格式简洁，支持快速检索。
a-stock-market-review-agent
每日盘后复盘 Agent。自动拉取龙虎榜数据、板块资金流向、涨停原因分析，交叉验证市场传闻与实际盘面表现，识别主力资金动向。
a-stock-technical-agent
技术分析 Agent。调用 baostock/a kshare 拉取历史 K 线，分析趋势线、支撑压力位、量价关系、均线系统，自动标注关键技术形态（头肩顶/双底/三角形突破等）。
l0-briefing-format
L0 望风者简报格式规范。定义情报源扫描结果的极简呈现格式：一屏内、不用表格、单行分隔、标题缩至25字。情报员+舆情兵双通道输出。
quant-backtrader
Backtrader 量化回测环境配置。Windows + CUDA 加速，支持多股票同时回测、自定义策略、绩效分析。内含安装步骤和常见坑。
quant-ml-stack
量化机器学习环境搭建。PyTorch CUDA 版本配置、conda 环境隔离、量化专用 Python 环境（quant310）的完整工具链（XGBoost/LightGBM/scikit-learn）。
quant-ml-tools
AI/ML 量化工具对比和选型指南。涵盖强化学习（FinRL）、金融 NLP（FinBERT）、自动因子挖掘（gplearn+alphalens）等工具的实际使用评价和坑点。
weekly-editor
周报总编 Agent。每周汇总 L1 各研究员团队的周报，提取核心观点、标注时效性，双写入 SQLite 知识库和 Markdown 报告。支持历史回溯。
